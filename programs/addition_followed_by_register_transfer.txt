; Vole Machine Program: Addition and Register Transfer
; Purpose: Add two numbers and move the result to another register.

200A ; Load immediate value 0A into register 0
2105 ; Load immediate value 05 into register 1
5201 ; Add registers 0 and 1, put result in register 2
4023 ; Move the contents of register 2 into register 3
33FF ; Store register 3 to address FF (screen output)
C000 ; Halt execution
