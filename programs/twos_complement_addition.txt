; Vole Machine Program: Two's Complement Addition
; Purpose: Add negative one and positive one.

20FF ; Load immediate value FF (-1) into register 0
2101 ; Load immediate value 01 (1) into register 1
5201 ; Add registers 0 and 1, put result in register 2
32FF ; Store register 2 to address FF (screen output)
C000 ; Halt execution
