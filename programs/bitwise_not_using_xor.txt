; Vole Machine Program: Bitwise Inversion
; Purpose: Invert all bits of a value using XOR with FF.

200F ; Load immediate value 0F into register 0
21FF ; Load immediate value FF into register 1
9201 ; XOR registers 0 and 1, put result in register 2
32FF ; Store register 2 to address FF (screen output)
C000 ; Halt execution
